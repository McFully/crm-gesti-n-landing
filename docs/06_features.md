## 1. Listado de Funcionalidades
El proyecto ofrece las siguientes capacidades funcionales completas:

- **Panel de Control Integrado:** Visualización en tiempo real del estado del sistema.
- **Gestión Local de Registros:** Alta, baja, modificación y consulta 100% offline.
- **Sistema de Temas Dinámico:** Transición impecable entre esquemas estéticos (Modo Día / Modo Noche).
- **Herramientas de Exportación:** Respaldos locales de datos configurados en el sistema.
