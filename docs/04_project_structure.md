## 1. Árbol de Directorios
Estructura física de carpetas escaneada para el proyecto **crm_gestión_landing**:

```text
- 📄 ABL-DJ-MIX-PRO-v1.0.0-Setup.exe
- 📄 favicon.ico
- 📄 index.html
- 📄 laptop.webp
- 📄 logo.webp
- 📄 styles.css

```

## 2. Descripción de Carpetas Críticas
- **/src** u **origen principal:** Alberga la lógica de negocio, módulos de motor y UI.
- **/public** o **/assets:** Recursos estáticos del sistema (imágenes, fuentes, iconos).
- **/docs:** Documentación técnica oficial del ecosistema.
