## 1. Estrategia de Testing
La calidad del software se valida mediante:

- **Pruebas de Integridad:** Comprobación de integridad del JSON en cada inicio.
- **Pruebas de UI (Sanity Tests):** Navegación completa por las vistas verificando que ningún elemento quede bloqueado.
