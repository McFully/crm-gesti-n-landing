## 1. Tecnologías Principales
A continuación se detalla el stack tecnológico implementado en **crm_gestión_landing**:

- **Motor / Entorno:** Node.js / Navegador Web
- **UI & Layout:** HTML5, CSS3, Javascript 
- **Estilos:** CSS nativo y adaptado (Paleta de colores optimizada)
- **Compilador/Empaquetador:** Herramientas nativas del ecosistema

## 2. Justificación Tecnológica
- **Privacidad y Velocidad:** Al correr localmente, se eliminan latencias de red ofreciendo respuestas instantáneas.
- **Aislamiento de Entorno:** Permite un comportamiento consistente sin dependencias de APIs en la nube de terceros.
