## 1. Archivos de Configuración Detectados
- **package.json:** Define el nombre, versión, scripts de arranque y dependencias del ecosistema.
- **tsconfig.json / jsconfig.json (si aplica):** Configuración de aliases y tipados para el compilador.
- **vite.config.js (si aplica):** Define la configuración de empaquetado ultra-rápido.
